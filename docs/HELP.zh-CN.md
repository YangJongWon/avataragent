# 使用帮助

[한국어](HELP.md) | [English](HELP.en.md) | [日本語](HELP.ja.md) | 简体中文

这是一款由 AI 员工在办公室里处理任务、由用户批准结果的应用。界面上方的标签是办公室、员工管理、模型管理、MCP 管理、损益·结算。除办公室以外的标签只对所有者（用密码进入的人）显示。

## 开始使用

- 一开始是 **模拟模式**。不调用真实 AI，只用模拟回复展示流程，所以不产生费用。右上角显示"模拟"就是这个模式。
- 要使用免费的真实 AI，请在 **模型管理** 标签的 OpenRouter 卡片中填入 API 密钥。保存密钥后，会自动切换为使用默认免费模型的"每人真实 AI"，无需重启服务器。请不要向免费端点发送机密或个人信息。
- 然后在 **员工管理** 中为每位员工选择模型，在办公室的白板上登记任务即可。
- **长按或右键点击** 右上角的"模拟"（真实 AI 时为"按员工 AI"）徽章，会开始使用演示。它会在界面各处贴上便签，依次展示大致的用法；同时员工们会反复演示处理一项 [演示] 任务的过程（交接任务、去书架调研、求助、退回·通过、等待批准、完成）。这只是界面上的模拟，不会保存，也不会调用 AI。键盘上 →/Enter 是下一步，← 是上一步，Esc 是结束。

## 办公室界面

- 默认有 5 个团队办公室（开发、人事、管理、客服、福利），通过上方的办公室标签切换。标签旁的数字是需要你确认的任务数（求助、等待批准）。
- 正在工作的员工在办公桌前，完成工作的员工在休息室。点击员工（移动端为长按）会打开菜单。
- 右键点击办公室标签（移动端为长按）会出现创建共享链接、关闭办公室的菜单。
- 用标签栏末尾的"+ 办公室"按钮添加办公室（仅所有者）。默认办公室和有任务进行中的办公室不能关闭。
- 屏幕较小时（手机），任务流程放在底部抽屉，求助和批准放在右侧抽屉。

## 分配任务

- 在办公室的 **白板** 上写下任务标题和说明，选择任务类型后登记。
- 每个办公室最多可将 10 项任务放入队列，前一项任务结束后下一项会自动开始。排队中的任务可以取消或修改流程。
- 通常的顺序是 受理（简报）→ 调研 → 撰写 → 审核 → 用户批准。

### 定时与重复任务

- 在任务登记窗口下方的 **何时执行** 中选择 立即 / 定时（一次）/ 每天 / 每周（选择星期）/ 每 N 小时，按钮会变成 **⏰ 预约**。
- 到了设定时间，团队会把这项任务贴到白板上。如果有其他任务正在进行，会进入队列；如果在工作时间之外，会在上班后开始。应用关闭期间错过的重复不会补做，而是从下一个时间继续。
- 在 **团队资料** 标签最上方的 ⏰ 定时任务中查看下次执行时间，可以用 **现在执行一次** 立即试运行，也可以关闭或删除。

## 任务流程（步骤设计）

- **固定流程**：直接使用与任务类型对应的默认顺序。
- **AI 设计**：组长 AI 查看任务后决定步骤和负责人，并留下理由。也可以在登记前先获取设计方案。
- **手动设计**：自己决定步骤的添加、删除、顺序、负责人和指示。最多 10 步。
- **条件循环**：可以给步骤加上"满足条件就返回前面的步骤"。例如："未达到审核标准就返回撰写，最多 2 次"。审核步骤默认带有此条件。
- 在流程界面打开"✋ 调整布局"后，可以拖动方框、改变大小；用"↺ 自动布局"恢复。

## 员工求助时

- 指示含糊时，员工会露出为难的表情并提问。任务会变成"请求帮助"状态，办公室标签上会出现数字。
- 选择一个选项、自己写答案，或者点击"自行推进"即可。
- 如果在规定时间（`HELP_TIMEOUT_SEC`，默认 180 秒）内没有回答，员工会自行做出假设并继续。

## 批准与修改要求

- 最后一步是用户批准。在右侧的报告面板中查看成果和审核意见，然后点击 **批准** 或 **要求修改**。
- 在修改要求中写明需要修改的地方，会返回撰写步骤重新撰写。
- 只有批准后结果才会生效，折算成人工成本的价值才会计入损益。
- 发送邮件之类的外部操作（MCP 工具的"批准后执行"）会在批准时一起执行。批准前可以逐项关闭。
- 实际上不会发送邮件，只会堆积在 **待发送箱** 中。

## 导出成果（Excel、Word、PDF、PowerPoint）

- 在报告标签的 **导出** 中下载 Markdown、CSV、Excel、Word、PDF、PowerPoint。只有查看权限也能下载。
- PDF 会打开打印页面，请使用浏览器的"另存为 PDF"。
- **用 AI 设计**：撰写员工决定文档、幻灯片或表格的排版，由服务器绘制。会放入关键数字卡片、图表、日程、对比等模块。报告中没有的数字会被自动去掉。
- **🔍 高质量**：把生成的文件转换成 PDF，审核员工看着页面指出问题，撰写员工进行修改（默认 2 轮）。需要安装 LibreOffice，AI 调用也会更多。
- Excel 设计会用真正的 Excel 公式加入合计·平均行、比例列、条件颜色和数据条。
- 如果通过修改要求改变了草稿，设计会恢复为默认。请再次点击"用 AI 设计"。

## 团队资料（邮箱、日程、咨询、推荐、预算）

- 右侧面板的团队资料标签中有各团队的资料。人事团队负责邮箱和日程，客服团队负责咨询箱，福利团队负责兴趣和推荐，管理团队负责各团队的预算上限。
- 打开自动检查后，有新邮件或新咨询时团队会自行开始任务。变更始终在批准后才生效。
- 可以用"📨 新邮件到达（模拟）"和"🎧 新咨询到达（模拟）"按钮放入模拟邮件和咨询，测试流程。

### 连接真实邮箱（人事团队）

- 在 **MCP 管理** 界面最上方的 **📮 邮箱账户连接** 中选择邮箱类型（Gmail、Naver、Daum·Kakao、手动输入），填入邮箱地址和 **应用专用密码**。保存前会先尝试登录。
  - Gmail：在 Google 账号中开启两步验证后，创建 [应用专用密码](https://myaccount.google.com/apppasswords) 并粘贴。
  - Naver·Daum：在邮箱设置中开启 IMAP。如果使用两步验证，请创建应用（程序）专用密码并填入。
  - 公司邮箱请先询问管理员是否可以使用 IMAP。公司的 Google Workspace 可能禁用了应用专用密码。
- **📥 获取新邮件** 会从收件箱最近 2 天的邮件中，一次最多获取 10 封尚未获取的邮件。打开自动检查后每 5 分钟获取一次，由团队自行整理。获取时只读取邮箱。
- **批准** 整理报告后，**也会同步到真实邮箱**。不会删除邮件或标记为已读。

  | 分类 | Gmail | Naver、Daum 等 |
  |---|---|---|
  | 日程 | `AvatarCast/일정` 标签（保留在收件箱） | 保持不变 |
  | 请求 | `AvatarCast/회신 필요` 标签（保留在收件箱） | 保持不变 |
  | 信息 | `AvatarCast/정보` 标签 + 归档 | 移到 `AvatarCast/정보` 文件夹 |
  | 广告 | `AvatarCast/광고` 标签 + 归档 | 移到 `AvatarCast/광고` 文件夹 |

- 应用专用密码只保存在这台电脑的服务器上，不会发送到界面。点击 **断开连接** 会一起删除。
- 邮件正文被视为来自外部的内容，员工不会执行邮件中写的指示。

## 员工管理

- 按办公室招聘和辞退员工。角色有管理者、调研员、撰写员、审核员 4 种。
- 每位员工可以选择不同的模型。模型列表是在模型管理标签中登记的模型。
- 同一角色有多位员工时，编排流程时可以为每一步选择负责人。
- 暂停某位员工后，任务会停在该员工负责的步骤。
- **性格·工作风格**：从均衡型、细致型、迅速型、创意型、亲切型、批判型中选择。每次都会把这种风格连同指示一起传给真实 AI（组织安全规则优先）。默认值为调研负责人细致型、审核负责人批判型，其余均衡型。迅速型写得更短，费用也更低。模拟模式下，工作指示书和调研笔记末尾会附上风格备注。

## 模型管理（连接 AI）

- 登记 **提供商** 后会确定员工帽子的形状和颜色，并填入 API 类型（OpenAI、Anthropic、Gemini、xAI、OpenAI 兼容地址）和密钥。
- **模型** 由 提供商 + 等级（装饰）+ API 模型 ID + 单价 组成。用"读取列表"可以获取密钥能使用的模型 ID 并进行选择（免费）。
- 新模型只需填入 API 模型 ID，**名称、等级和单价就会自动填写。** 如果有该提供商的密钥，会直接询问该模型（不行则询问同一提供商的其他模型），费用极低；没有密钥时，会根据内置的参考价目表或名称进行估算。下方会显示每个值的来源，请用"确认单价 ↗"查看提供商的价目表，必要时修改后保存。随时可以用"🤖 让 AI 填写"重新询问。
- **运行方式**：在"遵循 .env""模拟""每人真实 AI"中选择后立即切换。
- 密钥在界面上只显示最后 4 位。留空则使用 `.env` 中的密钥。
- DeepSeek、Ollama 等服务以"OpenAI 兼容"方式填入地址（Base URL）连接。点击"+ 登记提供商"中的 **快速填充**（DeepSeek、Mistral、OpenRouter、Groq、Upstage、Ollama）会自动填入名称和地址。
- 点击提供商卡片和编辑界面上的 **获取 API 密钥 ↗ / 付款·充值 ↗ / 价目表 ↗** 按钮，会在新标签页中打开该提供商网站的相应页面。登录和获取密钥请在该网站上自行完成，再把得到的密钥粘贴到卡片的"输入 API 密钥"栏中。

## MCP 管理（连接外部工具）

- 把搜索、Notion、GitHub、Slack 等外部功能作为 **MCP 服务器** 连接，供员工使用。
- 点击上方的按钮（网页搜索、Notion、GitHub、Slack、Gmail 等）会打开已填好必要字段的表单。没有列出的服务，用"手动输入"填写地址或命令。
- 表单上方的 **快捷方式 ↗** 按钮会在新标签页中打开该服务的设置页面，例如获取令牌、创建应用。出现连接错误或需要登录的服务器卡片上也会显示同样的按钮。
- 连接方式有两种。
  - **通过地址连接（HTTP）**：连接远程 MCP 服务器地址（`https://…/mcp`）。令牌作为密钥（HTTP 头）填入，通常名称为 `Authorization`，值为 `Bearer 令牌`。
  - **在本机运行（命令）**：用 `npx`、`uvx` 等命令启动 MCP 服务器。本机需要有 Node.js（npx）或 uv（uvx）。内置连接（网页搜索、Notion、网页读取）无需设置即可直接使用。出于安全考虑，自己输入命令的连接只能在运行应用的电脑上打开时添加或修改（通过外部地址访问的界面不行）。
- 打开 **使用 OAuth 登录** 后，保存时会打开该服务的登录窗口（如 Notion 登录）。无需另外创建令牌。
- 保存后点击 **检查连接** 会获取工具列表。每个工具可以选择"关闭""调研时自动""批准后执行"。建议读取类工具设为自动，发送邮件等写入类工具设为批准后执行。
- 在"使用的办公室"中决定哪些办公室的员工可以使用。
- 工具调用和结果会保留在任务的执行记录中。

### 连接 Slack

Slack 通过 OAuth 连接官方 MCP 服务器（`https://mcp.slack.com/mcp`）。Slack 不会自动注册应用，所以需要你自己创建一个 Slack 应用。

1. 在 [api.slack.com/apps](https://api.slack.com/apps) 用 **Create New App** 创建应用（From scratch，选择要使用的工作区）。
2. 在应用的 **OAuth & Permissions** 中，把本应用的回调地址填入 **Redirect URLs**。在 MCP 管理中打开 OAuth 后，界面上会显示地址。格式为 `访问地址/api/mcp-oauth/callback`。
   - Slack 通常只接受 `https://` 地址。如果 `http://localhost` 被拒绝，请把 HTTPS 外部地址（例如 Tailscale Serve）填入 `.env` 的 `PUBLIC_URL`，再用该地址访问并连接。
3. 在同一界面的 **User Token Scopes** 中填入需要的权限。如果只读，可以从 `search:read`、`channels:history`、`channels:read`、`users:read` 开始；如果要发送消息，再加上 `chat:write`。
4. 从应用的 **Basic Information** 中复制 **Client ID** 和 **Client Secret**。
5. 在 MCP 管理中点击 **Slack** 按钮，填入 Client ID 和 Client Secret 并保存，会打开 Slack 登录窗口。允许后即完成连接。
6. 工作区管理员需要允许 MCP 连接（或该应用）。如果是公司的工作区，请先询问管理员。
7. 检查连接后，建议把发送消息之类的工具设为"批准后执行"。

### 连接 Gmail（MCP，高级）

> 如果只是整理邮箱，**连接真实邮箱**（MCP 管理最上方，应用专用密码）要简单得多。下面是让员工在调研中搜索 Gmail 或创建草稿时使用的方法。

Gmail 通过 OAuth 连接 Google 官方 MCP 服务器（`https://gmailmcp.googleapis.com/mcp/v1`，预览版）。只能搜索·阅读邮件、在草稿箱中撰写草稿和管理标签，**不能发送邮件。** 草稿请在 Gmail 中确认后自己发送。在 MCP 管理中点击 **Gmail** 按钮，会显示下列各步骤的快捷按钮。

1. 用 **① 启用 Gmail API**、**① 启用 Gmail MCP API** 按钮，在 Google Cloud 项目中把两个 API 设为"启用"。如果没有项目，请先创建一个。
2. 在 **② 同意屏幕·测试用户** 中设定应用名称，把受众设为"外部"，发布状态设为"测试"，并在测试用户中加入自己的 Gmail 地址。
3. 在 **③ 创建客户端** 中选择类型"Web 应用"，在 **已获授权的重定向 URI** 中填入表单上显示的 Redirect URL（例如 `http://localhost:8787/api/mcp-oauth/callback`）。Google 接受 `http://localhost` 地址。
4. 把创建好的客户端的 **客户端 ID** 和 **客户端密钥** 填入表单。"请求的权限"（`OAUTH_SCOPES`）已预先填好读取（`gmail.readonly`）和草稿（`gmail.compose`）。
5. 保存后会打开 Google 登录窗口。如果出现"未经验证的应用"警告，因为是你自己的应用，点击"继续"并允许即可。
6. 测试模式下，每 7 天登录会失效。届时请再次点击服务器卡片上的 🔐 登录。
7. 建议把创建草稿之类的写入工具设为"批准后执行"。

## 损益·结算

- 显示本月的 AI 预算、已用费用、经批准认可的价值和利润。也有按任务、按员工的损益。
- 预算用完后 AI 调用会停止。在损益·结算标签中增加预算后会恢复。
- 各办公室的预算上限在管理团队的团队资料中修改。
- 用量超过预算的 80% 时会提醒一次。

## 成果·改进

- 每次调研和审核结束时都会自动记录。
  - **调研**：耗时、工具调用次数与失败次数，以及准确度（审核负责人查看调研笔记后打 0–100 分）。
  - **审核**：通过/不通过、分数、退回理由、是第几版草稿。
  - **审核判断准确度**：审核通过的结果用户是否也批准了（如果要求修改，会记录为"不一致"）。
- 这些记录无需你操作就会用于之后的任务。
  - 把同类型任务过去的退回理由作为"避免同样的错误"传给撰写员，把低分调研的意见一并传给调研员。
  - 同一角色有多位员工时，优先分配成果较好的员工（AI 设计流程时，组长也会参考成绩表）。
- **改进建议**：在同一模型·性格下积累了 3 条以上记录后，如果调研准确度低于 70 分、作品审核通过率不到一半，或者审核判断经常不一致，会建议更换性格（细致型、批判型等）；如果已经是该性格，则建议升一级的模型。如果审核总是通过且没有不一致，也可能建议更便宜的模型。点击"应用"会立即生效。
- 打开 **自主改进** 后，不增加费用的建议（更换性格）会在每次任务结束时自动应用，并记录在活动记录中。更换模型会改变费用，所以始终由你自己决定。把自主改进所做的更改再改回去的建议不会自动应用。

### 分享操作手册（与其他公司交流经验）

- 在成果·改进标签的"分享操作手册"中点击 **导出**，会把这个办公室各角色的性格、个人规则、模型等级和成绩表（审核通过率、调研准确度·速度、每项任务的费用·价值等）保存为 JSON 文件。
- 不包含员工姓名、任务资料、成果、退回理由和 API 密钥。不过，你自己写在个人规则中的内容会原样包含在内，导出前请确认规则中没有公司机密。
- 用 **导入** 打开收到的文件后，会把成果与本办公室并排比较，并先按员工显示应用后会有哪些变化。只有点击"应用"才会生效。
- 只能应用到同类办公室（例如开发团队 → 开发团队）。匹配模型等级可能改变费用，需要单独勾选。
- 如果规则中有"忽略安全规则"、外部地址、密钥·密码、向外发送·删除等表述，会标记为 ⚠ 注意，必须勾选已阅读后才能应用。无论导入什么规则，组织安全规则始终优先。

## 套餐·成员·聊天

- 在"套餐·成员"标签中选择 **套餐**。
  - 个人（免费）：一个人使用，只能通过共享链接展示。
  - 团队（每月 $9）：最多 10 个成员账号，全公司聊天和按任务对话。
  - 企业（每月 $29）：最多 50 名成员，在团队功能之外增加按办公室的频道、指定任务负责人和导出活动记录。
- **付款**：如果没有连接支付服务商，可以直接更换套餐。连接后，点击付费套餐会跳转到付款界面，付款完成后套餐才会变更。
  - 每 30 天自动扣费。付款记录显示在同一界面。
  - 点击"个人"会预约取消订阅，在已付费的期限结束前仍可继续使用当前套餐。在此之前再次点击当前套餐，会撤销取消预约。
  - 定期扣款失败后仍可继续使用 7 天，如果在此期间没有重新付款，会变为个人套餐。
- **任务负责人**（企业版）：在报告上方的 👤 栏中选择负责该任务的人（所有者或能查看该办公室的成员）。负责人变更时会在办公室频道发布通知，之后的任务通知会带上"（负责人：姓名）"。
- **导出活动记录**（企业版，仅所有者）：在"套餐·成员"标签中选择时间段，以 CSV（可直接用 Excel 打开）或 JSON 下载。包含任务进度、批准、AI 费用以及规则·成员·套餐的变更。
- **成员账号** 由所有者设定 ID、姓名、初始密码（8 位以上）、权限（查看/处理任务/管理办公室）和可查看的办公室来创建。成员在登录界面用 ID 和密码登录（所有者只需密码）。必须开启访问密码（ACCESS_PASSWORD）才能登录。
- 修改密码或停用账号后，该账号已有的登录会立即断开。把套餐降为个人后成员无法登录，但账号和对话会保留。
- 用右上角的"💬 聊天"打开 **聊天**。只有所有者和成员可以使用，通过共享链接进入的人看不到。只显示自己能查看的办公室的频道和任务。
- 用报告上方的"💬 任务对话"针对每项任务单独交流，在那里点击"分享到公司频道"（企业版为办公室频道）会发布任务卡片。点击卡片会直接跳转到该任务。
- 员工求助、等待批准、任务完成或中止时，聊天中会出现 🤖 通知。
- 默认情况下 AI 员工看不到聊天。写在任务对话中的消息或附带任务卡片的消息，可以点击"🤖 转交给 AI 员工"有选择地转交（需处理任务权限以上）。
  - **作为参考备注转交**：任务排队或进行中时。之后的调研和草稿会体现这条备注，审核也会确认是否已体现。它会以 💬 保留在报告的"审核"标签中。
  - **作为求助回复转交**：员工正在求助时，把这条消息作为回答发送。
  - **作为修改要求转交**：成果等待批准时，用这条消息发送修改要求。
  - 每条消息只能转交一次，谁以何种方式转交会显示在消息下方。已结束的任务无法转交。

## 共享与权限

- 在办公室标签菜单（右键，移动端为长按）中，为该办公室或全部办公室创建共享链接和二维码。
- 权限可在 **查看**（只读）、**处理任务**（登记任务·回答求助·批准）、**管理办公室**（还包括员工·团队资料·模拟）中选择。
- 可以设置有效期（1·7·30 天、无），并随时收回。收回后正在访问的界面也会立即断开。
- 添加·删除办公室、公司预算、办公室预算上限、共享管理、模型·MCP 管理只有所有者可以操作。

## 帮助 AI

- 可以在右上角的 **❓ 帮助** 中询问用法。它会从本文档和运营指南中找到相关部分来回答。
- 在真实 AI 模式下，由你正在查看的办公室的管理者员工回答，费用计入该办公室的 AI 费用（每个问题几韩元左右）。在模拟模式或查看权限下，只会找出并显示相关的帮助内容。

## 常见问题

- **任务停住了**：请看办公室标签上的数字。如果是求助或等待批准，就轮到你了。预算用完或员工被暂停时也会停住。
- **切换到真实 AI 后出错**：在模型管理中用"读取列表"确认密钥是否正确，并确认模型 ID 是否是该提供商使用的名称。
- **花了多少钱**：可以在损益·结算标签或任务的损益标签中查看。
- **邮件真的会发出去吗**：不会。只会堆积在待发送箱中。
- **从其他设备访问**：请参阅运营指南中的"从其他设备访问"。请务必设置密码（`ACCESS_PASSWORD`）。
