# 사용 도움말

AI 직원들이 사무실에서 업무를 처리하고, 사용자가 결과를 승인하는 앱이에요. 화면 위쪽 탭은 사무실, 직원 관리, 모델 관리, MCP 관리, 손익·결산이에요. 사무실 외의 탭은 주인(비밀번호로 들어온 사람)에게만 보여요.

## 처음 시작하기

- 처음에는 **시뮬레이션 모드**예요. 실제 AI를 부르지 않고 가짜 응답으로 흐름만 보여 줘서 비용이 들지 않아요. 오른쪽 위에 "시뮬레이션"이라고 보이면 이 모드예요.
- 무료 실제 AI를 쓰려면 **모델 관리** 탭의 OpenRouter 카드에 API 키를 넣어요. 키를 저장하면 기본 무료 모델을 쓰는 "직원별 실제 AI"로 자동 전환되며 서버를 다시 켤 필요는 없어요. 무료 엔드포인트에는 기밀·개인정보를 보내지 마세요.
- 그다음 **직원 관리**에서 직원마다 모델을 고르고, 사무실 칠판에서 업무를 등록하면 돼요.
- 오른쪽 위 "시뮬레이션"(실제 AI면 "직원별 AI") 배지를 **길게 누르거나 우클릭**하면 사용법 데모가 시작돼요. 화면 곳곳에 메모를 붙여 가며 대략적인 쓰는 법을 차례로 보여 주고, 그동안 직원들이 [데모] 업무 하나를 처리하는 모습(업무 전달, 책장 조사, 도움 요청, 반려·통과, 승인 대기, 완료)이 반복 재생돼요. 화면에서만 흉내 내는 거라 저장되거나 AI를 부르지 않아요. 키보드로는 →/Enter가 다음, ←가 이전, Esc가 끝내기예요.

## 사무실 화면

- 사무실은 팀별로 5개(개발·인사·경영·서포터·복지)가 기본으로 있고, 위쪽 사무실 탭으로 옮겨 다녀요. 탭 옆 숫자는 내가 확인해야 할 업무(도움 요청, 승인 대기) 수예요.
- 일하는 직원은 책상에, 일이 끝난 직원은 휴게실에 있어요. 직원을 누르면(모바일은 길게 누르기) 메뉴가 열려요.
- 사무실 탭을 우클릭(모바일은 길게 누르기)하면 공유 링크 만들기, 사무실 닫기 메뉴가 나와요.
- 사무실 추가는 탭 줄 끝의 "+ 사무실" 버튼으로 해요(주인만). 기본 사무실과 업무가 진행 중인 사무실은 닫을 수 없어요.
- 화면 크기가 작으면(휴대폰) 업무 여정은 아래 서랍, 도움 요청과 승인은 오른쪽 서랍에 들어가요.

## 업무 맡기기

- 사무실의 **칠판**에서 업무 제목과 설명을 쓰고 업무 유형을 골라 등록해요.
- 업무는 사무실마다 최대 10건까지 대기열에 넣을 수 있고, 앞 업무가 끝나면 다음 업무가 자동으로 시작돼요. 대기 중인 업무는 취소하거나 여정을 고칠 수 있어요.
- 진행 순서는 보통 접수(브리프) → 조사 → 작성 → 검토 → 사용자 승인이에요.

## 업무 여정 (단계 설계)

- **정해진 여정**: 업무 유형에 맞는 기본 순서를 그대로 써요.
- **AI가 설계**: 팀장 AI가 업무를 보고 단계와 담당자를 정하고 이유를 남겨요. 등록 전에 미리 설계를 받아 볼 수도 있어요.
- **직접 설계**: 단계 추가·삭제·순서·담당자·지시를 직접 정해요. 최대 10단계예요.
- **조건 루프**: 단계에 "조건이 맞으면 앞 단계로 되돌아가기"를 붙일 수 있어요. 예: "검토 기준에 못 미치면 작성으로, 최대 2회". 검토 단계에는 기본으로 붙어 있어요.
- 여정 화면에서 "✋ 배치 조정"을 켜면 상자를 끌어 옮기고 크기를 바꿀 수 있고, "↺ 자동 배치"로 되돌려요.

## 직원이 도움을 요청할 때

- 지시가 모호하면 직원이 곤란한 표정을 짓고 질문해요. 업무가 "도움 요청" 상태가 되고 사무실 탭에 숫자가 떠요.
- 선택지를 고르거나, 직접 답을 쓰거나, "알아서 진행"을 누르면 돼요.
- 정해진 시간(`HELP_TIMEOUT_SEC`, 기본 180초) 안에 답이 없으면 직원이 가정을 세우고 진행해요.

## 승인과 수정 요청

- 마지막 단계는 사용자 승인이에요. 오른쪽 보고서 패널에서 결과물과 검수 의견을 보고 **승인** 또는 **수정 요청**을 눌러요.
- 수정 요청에 고칠 점을 쓰면 작성 단계로 돌아가서 다시 써요.
- 승인해야 결과가 반영되고, 인건비 환산 가치가 손익에 잡혀요.
- 메일 발송 같은 바깥 작업(MCP 도구의 "승인 후 실행")은 승인할 때 함께 실행돼요. 승인 전에 작업마다 끌 수 있어요.
- 실제 메일은 보내지 않고 **발송 대기함**에만 쌓여요.

## 결과물 내보내기 (Excel, Word, PDF, PowerPoint)

- 보고서 탭의 **내보내기**에서 Markdown, CSV, Excel, Word, PDF, PowerPoint로 받아요. 보기 권한만 있어도 받을 수 있어요.
- PDF는 인쇄용 페이지가 열리면 브라우저의 "PDF로 저장"을 눌러요.
- **AI로 디자인**: 작성 직원이 문서·슬라이드·엑셀의 배치를 정하고 서버가 그려요. 핵심 숫자 카드, 차트, 일정, 비교 같은 블록이 들어가요. 보고서에 없는 숫자는 자동으로 빠져요.
- **🔍 고품질**: 만든 파일을 PDF로 바꿔 검토 직원이 화면을 보고 지적하면 작성 직원이 고쳐요(기본 2번). LibreOffice가 설치되어 있어야 하고, AI 호출이 더 들어요.
- 엑셀 디자인은 합계·평균 행, 비율 열, 조건부 색, 데이터 막대를 진짜 Excel 수식으로 넣어요.
- 초안을 수정 요청해서 바뀌면 디자인은 기본으로 돌아가요. 다시 "AI로 디자인"을 눌러 주세요.

## 팀 자료 (메일함, 일정, 문의함, 추천, 예산)

- 오른쪽 패널의 팀 자료 탭에 팀별 자료가 있어요. 인사팀은 메일함과 일정, 서포터팀은 문의함, 복지팀은 관심사와 추천, 경영팀은 팀별 예산 상한을 다뤄요.
- 자동 확인을 켜면 새 메일·문의가 있을 때 팀이 알아서 업무를 시작해요. 반영은 항상 승인 후에 돼요.
- "📨 새 메일 도착 (시뮬레이션)", "🎧 새 문의 도착 (시뮬레이션)" 버튼으로 가짜 메일·문의를 넣어 흐름을 시험할 수 있어요.

## 직원 관리

- 사무실별로 직원을 뽑고(고용) 내보내요. 역할은 관리자·조사원·작성자·검수자 4가지예요.
- 직원마다 모델을 고를 수 있어요. 모델 목록은 모델 관리 탭에서 등록한 것이에요.
- 같은 역할 직원이 여럿이면 여정을 짤 때 단계마다 담당자를 고를 수 있어요.
- 직원을 일시정지하면 그 직원의 단계에서 업무가 멈춰요.
- **성격·일하는 스타일**: 균형형, 꼼꼼형, 신속형, 창의형, 친절형, 비판형 중에서 골라요. 실제 AI에게는 매번 이 스타일이 지시와 함께 전달돼요(조직 안전 규칙이 더 우선). 기본값은 조사 담당 꼼꼼형, 검토 담당 비판형, 나머지 균형형이에요. 신속형은 글이 짧아져 비용도 줄어요. 시뮬레이션에서는 작업 지시서와 조사 메모 끝에 스타일 메모가 붙어요.

## 모델 관리 (AI 연결)

- **회사**를 등록하면 직원 모자 모양과 색이 정해지고, API 종류(OpenAI, Anthropic, Gemini, xAI, OpenAI 호환 주소)와 키를 넣어요.
- **모델**은 회사 + 등급(장식) + API 모델 ID + 단가예요. "목록 불러오기"로 키가 쓸 수 있는 모델 ID를 받아 고를 수 있어요(비용 없음).
- 새 모델은 API 모델 ID만 넣으면 **이름·등급·단가가 자동으로 채워져요.** 그 회사 키가 있으면 해당 모델(안 되면 같은 회사의 다른 모델)에게 직접 물어보고(아주 적은 비용), 키가 없으면 내장 참고 가격표나 이름으로 추정해요. 어디서 온 값인지 아래에 표시되니 "단가 확인 ↗"로 회사 가격표를 보고 필요하면 고쳐서 저장하세요. "🤖 AI에게 물어 채우기"로 언제든 다시 물을 수 있어요.
- **실행 방식**: ".env 따르기", "시뮬레이션", "직원별 실제 AI" 중에서 고르면 바로 바뀌어요.
- 키는 화면에 끝 4자리만 보여요. 비워 두면 `.env`의 키를 써요.
- DeepSeek, Ollama 같은 서비스는 "OpenAI 호환"으로 주소(Base URL)를 넣어 연결해요. "+ 회사 등록"의 **빠른 채우기**(DeepSeek·Mistral·OpenRouter·Groq·Upstage·Ollama)를 누르면 이름과 주소가 채워져요.
- 회사 카드와 편집 화면의 **API 키 발급 ↗ / 결제·충전 ↗ / 가격표 ↗** 버튼을 누르면 그 회사 사이트의 해당 페이지가 새 탭으로 열려요. 로그인과 키 발급은 그 사이트에서 직접 하고, 받은 키를 카드의 "API 키 입력" 칸에 붙여 넣으면 돼요.

## MCP 관리 (외부 도구 연결)

- 검색, Notion, GitHub, Slack 같은 바깥 기능을 **MCP 서버**로 연결해 직원이 쓰게 해요.
- 위쪽 버튼(웹 검색, Notion, GitHub, Slack, Gmail 등)을 누르면 필요한 칸이 채워진 양식이 열려요. 없는 서비스는 "직접 입력"으로 주소나 명령을 넣어요.
- 양식 위의 **바로가기 ↗** 버튼은 토큰 발급, 앱 만들기 같은 그 서비스의 설정 페이지를 새 탭으로 열어 줘요. 연결 오류가 나거나 로그인이 필요한 서버 카드에도 같은 버튼이 보여요.
- 연결 방식은 두 가지예요.
  - **주소로 연결(HTTP)**: 원격 MCP 서버 주소(`https://…/mcp`)에 연결해요. 토큰은 비밀값(HTTP 헤더)으로 넣고, 보통 이름 `Authorization`, 값 `Bearer 토큰`이에요.
  - **이 PC에서 실행(명령)**: `npx`, `uvx` 같은 명령으로 MCP 서버를 띄워요. 이 PC에 Node.js(npx)나 uv(uvx)가 있어야 해요. 기본 제공 연결(웹 검색, Notion, 웹 페이지 읽기)은 따로 설정 없이 바로 쓸 수 있어요. 명령을 직접 입력하는 연결은 보안을 위해 앱을 실행 중인 PC에서 열었을 때만 등록하거나 바꿀 수 있어요(외부 주소로 접속한 화면에서는 안 돼요).
- **OAuth 로그인 사용**을 켜면 저장할 때 그 서비스의 로그인 창이 열려요(Notion 로그인 등). 토큰을 따로 만들 필요가 없어요.
- 저장 후 **연결 확인**을 누르면 도구 목록을 받아 와요. 도구마다 "끔", "조사 때 자동", "승인 후 실행"을 고를 수 있어요. 읽기 도구는 자동으로, 메일 발송 같은 쓰기 도구는 승인 후 실행을 권해요.
- "쓸 사무실"에서 어느 사무실 직원이 쓸지 정해요.
- 도구 호출과 결과는 업무의 실행 기록에 남아요.

### Slack 연결하기

Slack은 공식 MCP 서버(`https://mcp.slack.com/mcp`)를 OAuth로 연결해요. Slack은 앱을 자동으로 등록해 주지 않아서 Slack 앱을 직접 하나 만들어야 해요.

1. [api.slack.com/apps](https://api.slack.com/apps)에서 **Create New App**으로 앱을 만들어요(From scratch, 쓸 워크스페이스 선택).
2. 앱의 **OAuth & Permissions**에서 **Redirect URLs**에 이 앱의 콜백 주소를 넣어요. MCP 관리에서 OAuth를 켜면 화면에 주소가 보여요. 형식은 `접속 주소/api/mcp-oauth/callback`이에요.
   - Slack은 보통 `https://` 주소만 받아요. `http://localhost`가 거절되면 HTTPS 외부 주소(예: Tailscale Serve)를 `.env`의 `PUBLIC_URL`에 넣고 그 주소로 접속해서 연결해요.
3. 같은 화면의 **User Token Scopes**에 쓸 권한을 넣어요. 읽기만 쓸 거면 `search:read`, `channels:history`, `channels:read`, `users:read` 정도로 시작하고, 메시지를 보내려면 `chat:write`를 더해요.
4. 앱의 **Basic Information**에서 **Client ID**와 **Client Secret**을 복사해요.
5. MCP 관리에서 **Slack** 버튼을 누르고 Client ID와 Client Secret을 넣고 저장하면 Slack 로그인 창이 열려요. 허용하면 연결돼요.
6. 워크스페이스 관리자가 MCP 연결(또는 그 앱)을 허용해야 해요. 회사 워크스페이스라면 관리자에게 먼저 물어보세요.
7. 연결 확인 후 메시지 보내기 같은 도구는 "승인 후 실행"으로 두는 걸 권해요.

### Gmail 연결하기

Gmail은 구글 공식 MCP 서버(`https://gmailmcp.googleapis.com/mcp/v1`, 미리보기)를 OAuth로 연결해요. 메일 검색·읽기와 임시보관함 초안 작성, 라벨 관리만 되고 **메일 발송은 안 돼요.** 초안은 Gmail에서 확인하고 직접 보내요. MCP 관리에서 **Gmail** 버튼을 누르면 아래 단계의 바로가기 버튼이 보여요.

1. **① Gmail API 사용**, **① Gmail MCP API 사용** 버튼으로 구글 클라우드 프로젝트에서 두 API를 "사용"으로 켜요. 프로젝트가 없으면 먼저 하나 만들어요.
2. **② 동의 화면·테스트 사용자**에서 앱 이름을 정하고, 대상을 "외부"로, 게시 상태를 "테스트"로 두고, 테스트 사용자에 내 Gmail 주소를 넣어요.
3. **③ 클라이언트 만들기**에서 유형을 "웹 애플리케이션"으로 고르고, **승인된 리디렉션 URI**에 양식에 보이는 Redirect URL(예: `http://localhost:8787/api/mcp-oauth/callback`)을 넣어요. 구글은 `http://localhost` 주소를 받아 줘요.
4. 만든 클라이언트의 **클라이언트 ID**와 **클라이언트 보안 비밀**을 양식에 넣어요. "요청할 권한"(`OAUTH_SCOPES`)은 읽기(`gmail.readonly`)와 초안(`gmail.compose`)으로 미리 채워져 있어요.
5. 저장하면 구글 로그인 창이 열려요. "확인되지 않은 앱" 경고가 나오면 내 앱이니 "계속"을 눌러 허용해요.
6. 테스트 모드에서는 7일마다 로그인이 풀려요. 그때 서버 카드의 🔐 로그인을 다시 눌러요.
7. 초안 만들기 같은 쓰기 도구는 "승인 후 실행"으로 두는 걸 권해요.

## 손익·결산

- 이번 달 AI 예산, 쓴 비용, 승인으로 인정된 가치, 이익을 보여 줘요. 업무별·직원별 손익도 있어요.
- 예산을 다 쓰면 AI 호출이 멈춰요. 손익·결산 탭에서 예산을 늘리면 다시 돌아가요.
- 사무실별 예산 상한은 경영팀 팀 자료에서 바꿔요.
- 사용량이 예산의 80%를 넘으면 한 번 알려 줘요.

## 성과·개선

- 조사와 검수가 끝날 때마다 자동으로 기록돼요.
  - **조사**: 걸린 시간, 도구 호출 수와 실패, 그리고 정확도(검수 담당이 조사 메모를 보고 0~100점으로 매겨요).
  - **검수**: 합격/불합격, 점수, 반려 사유, 몇 번째 초안이었는지.
  - **검수 판단 정확도**: 검수에서 통과시킨 결과를 사용자도 승인했는지(수정 요청을 하면 "어긋남"으로 기록돼요).
- 기록은 따로 손대지 않아도 다음 업무에 쓰여요.
  - 같은 유형 업무의 지난 반려 사유를 작성자에게 "같은 실수를 피할 것"으로, 낮은 점수를 받은 조사의 지적을 조사 담당에게 함께 전달해요.
  - 같은 역할 직원이 여럿이면 성과가 좋은 직원을 먼저 배정해요(AI 여정 설계 때도 팀장이 성과표를 참고해요).
- **개선 제안**: 같은 모델·성격으로 3번 이상 기록이 쌓였는데 조사 정확도가 70점 미만이거나, 작성물 검수 통과가 절반 미만이거나, 검수 판단이 자주 어긋나면 성격(꼼꼼형·비판형 등) 변경을, 이미 그 성격이면 한 단계 위 모델을 제안해요. 검수가 늘 통과하고 어긋남도 없으면 더 싼 모델을 제안하기도 해요. "적용"을 누르면 바로 바뀌어요.
- **자율 개선**을 켜면 비용이 늘지 않는 제안(성격 변경)은 업무가 끝날 때마다 알아서 반영하고 활동 기록에 남겨요. 모델 변경은 비용이 달라지므로 항상 직접 결정해요. 자율 개선으로 바꾼 것을 다시 원래대로 되돌리는 제안은 자동으로 반영하지 않아요.

### 플레이북 공유 (다른 회사와 노하우 주고받기)

- 성과·개선 탭의 "플레이북 공유"에서 **내보내기**를 누르면 이 사무실의 역할별 성격, 개인 규칙, 모델 등급과 성과표(검수 통과율, 조사 정확도·속도, 업무당 비용·가치 등)가 JSON 파일로 저장돼요.
- 직원 이름, 업무 자료, 결과물, 반려 사유, API 키는 들어가지 않아요. 단, 개인 규칙에 직접 적은 내용은 그대로 들어가니 내보내기 전에 규칙에 회사 기밀이 없는지 확인하세요.
- **가져오기**로 받은 파일을 열면 성과를 이 사무실과 나란히 비교하고, 적용하면 무엇이 바뀌는지 직원별로 먼저 보여 줘요. "적용"을 눌러야만 바뀌어요.
- 같은 종류의 사무실(예: 개발팀 → 개발팀)에만 적용할 수 있어요. 모델 등급 맞추기는 비용이 달라질 수 있어 따로 체크해야 해요.
- 규칙에 "안전 규칙 무시", 외부 주소, 키·비밀번호, 외부로 보내기·지우기 같은 표현이 있으면 ⚠ 주의로 표시하고, 읽어 봤다고 체크해야 적용돼요. 어떤 규칙이 들어와도 조직 안전 규칙이 항상 우선해요.

## 플랜·구성원·채팅

- **플랜**은 "플랜·구성원" 탭에서 골라요.
  - 개인(무료): 혼자 쓰고, 공유 링크로 보여 주기만 해요.
  - 팀(월 $9): 구성원 계정 10명까지, 회사 전체 채팅과 업무별 대화.
  - 비즈니스(월 $29): 구성원 50명까지, 팀 기능에 사무실별 채널, 업무 담당자 지정, 활동 기록 내보내기 추가.
- **결제**: 결제사가 연결되지 않았으면 플랜을 바로 바꿀 수 있어요. 연결되면 유료 플랜을 누를 때 결제 화면으로 이동하고, 결제가 끝나야 플랜이 바뀌어요.
  - 30일마다 자동 결제돼요. 결제 내역은 같은 화면에 나와요.
  - "개인"을 누르면 구독 해지가 예약되고, 이미 낸 기간이 끝날 때까지는 지금 플랜을 그대로 써요. 그 전에 지금 플랜을 다시 누르면 해지 예약이 취소돼요.
  - 정기 결제가 실패하면 7일 동안은 그대로 쓸 수 있고, 그 안에 다시 결제하지 않으면 개인 플랜으로 바뀌어요.
- **업무 담당자**(비즈니스): 보고서 위의 👤 칸에서 그 업무를 맡을 사람(소유자 또는 그 사무실을 볼 수 있는 구성원)을 골라요. 담당자가 바뀌면 사무실 채널에 알림이 올라가고, 이후 업무 알림에 "(담당: 이름)"이 붙어요.
- **활동 기록 내보내기**(비즈니스, 소유자만): "플랜·구성원" 탭에서 기간을 정해 CSV(엑셀에서 바로 열림) 또는 JSON으로 받아요. 업무 진행, 승인, AI 비용, 규칙·구성원·플랜 변경까지 모두 들어 있어요.
- **구성원 계정**은 소유자가 아이디·이름·첫 비밀번호(8자 이상)·권한(보기/업무 처리/사무실 관리)·볼 수 있는 사무실을 정해 만들어요. 구성원은 로그인 화면에서 아이디와 비밀번호로 들어와요(소유자는 비밀번호만). 접속 비밀번호(ACCESS_PASSWORD)가 켜져 있어야 로그인할 수 있어요.
- 비밀번호를 바꾸거나 사용 중지하면 그 계정의 기존 로그인이 바로 끊겨요. 플랜을 개인으로 낮추면 구성원은 로그인할 수 없지만 계정과 대화는 남아 있어요.
- **채팅**은 오른쪽 위 "💬 채팅"으로 열어요. 소유자와 구성원만 쓸 수 있고 공유 링크로 들어온 사람에게는 보이지 않아요. 자기가 볼 수 있는 사무실의 채널과 업무만 보여요.
- 보고서 위의 "💬 업무 대화"로 업무마다 따로 이야기하고, 거기서 "회사 채널에 공유"(비즈니스는 사무실 채널)를 누르면 업무 카드가 올라가요. 카드를 누르면 그 업무로 바로 이동해요.
- 직원이 도움을 요청하거나, 승인을 기다리거나, 업무가 끝나거나 중단되면 채팅에 🤖 알림이 올라와요.
- 채팅은 기본적으로 AI 직원이 보지 않아요. 업무 대화에 쓴 메시지나 업무 카드가 붙은 메시지는 "🤖 AI 직원에게 전달"을 눌러 골라서 넘길 수 있어요(업무 처리 권한 이상).
  - **참고 메모로 전달**: 업무가 대기·진행 중일 때. 이후 조사·초안에 반영하고, 검수도 메모가 반영됐는지 확인해요. 보고서의 "검수" 탭에 💬로 남아요.
  - **도움 요청 답변으로 전달**: 직원이 도움을 요청 중일 때, 그 메시지를 답으로 보내요.
  - **수정 요청으로 전달**: 결과물이 승인을 기다릴 때, 그 메시지로 수정 요청을 보내요.
  - 메시지 하나는 한 번만 전달되고, 누가 어떻게 전달했는지 메시지 아래에 표시돼요. 끝난 업무에는 전달할 수 없어요.

## 공유와 권한

- 사무실 탭 메뉴(우클릭, 모바일은 길게 누르기)에서 그 사무실 또는 전체 사무실의 공유 링크와 QR을 만들어요.
- 권한은 **보기**(읽기만), **업무 처리**(업무 등록·도움 답변·승인), **사무실 관리**(직원·팀 자료·시뮬레이션까지) 중에서 골라요.
- 만료(1·7·30일, 없음)를 정할 수 있고 언제든 회수할 수 있어요. 회수하면 접속 중인 화면도 바로 끊겨요.
- 사무실 추가·삭제, 회사 예산, 사무실 예산 상한, 공유 관리, 모델·MCP 관리는 주인만 할 수 있어요.

## 도움말 AI

- 오른쪽 위 **❓ 도움말**에서 사용법을 물어볼 수 있어요. 이 문서와 운영 가이드에서 관련 부분을 찾아 답해요.
- 실제 AI 모드에서는 지금 보고 있는 사무실의 관리자 직원이 답하고, 비용은 그 사무실 AI 비용으로 잡혀요(질문 하나에 몇 원 수준). 시뮬레이션 모드나 보기 권한에서는 관련 도움말 부분만 찾아서 보여 줘요.

## 자주 묻는 질문

- **업무가 멈춰 있어요**: 사무실 탭 숫자를 보세요. 도움 요청이나 승인 대기면 내 차례예요. 예산을 다 썼거나 직원이 일시정지된 경우에도 멈춰요.
- **실제 AI로 바꿨는데 오류가 나요**: 모델 관리에서 키가 맞는지 "목록 불러오기"로 확인하고, 모델 ID가 그 회사에서 쓰는 이름인지 확인해요.
- **비용이 얼마나 들었는지**: 손익·결산 탭, 또는 업무의 손익 탭에서 볼 수 있어요.
- **메일이 실제로 나가나요**: 아니요. 발송 대기함에만 쌓여요.
- **다른 기기에서 접속하려면**: 운영 가이드의 "다른 기기에서 접속하기"를 보세요. 비밀번호(`ACCESS_PASSWORD`)를 꼭 정해 두세요.
