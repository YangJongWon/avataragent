## Development and checks

- Setup and running: "Developer setup" in [README.en.md](README.en.md)
- Before submitting, make sure `npm run typecheck` and `npm run test:unit` pass.

## Sharing themes and flows

Themes, flows and playbooks are community content, not code contributions. No CLA is needed: put the license you want in each package's `license` field and share it.
